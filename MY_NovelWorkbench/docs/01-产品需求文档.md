## 1. 产品定位

一款 **AI 辅助的小说创作工作台**，三大核心理念：

1. **节点工作流**（参考 ComfyUI）：以「蓝图 + 节点 + 连线」组织创作过程，蓝图画布为黑色网格背景，节点可自由拖动，画布可自由缩放
2. **双向链接**（参考 Obsidian）：蓝图与节点之间以链接互相引用，并提供全局图谱式总览
3. **AI 辅助创作**：根据节点自带的提示词信息、前后节点与上级蓝图的链接关系自动组装上下文，支持多类 AI API

## 2. 术语表

| 术语 | 定义 |
|---|---|
| 小说（项目） | 创作的顶层容器，本质为一个**目录**，目录内进行所有创作 |
| 蓝图（Blueprint） | 节点工作流文件：黑色网格背景的画布，可在其中创建节点并连线；蓝图本身也可作为节点嵌入其他蓝图（**子图嵌套**） |
| 节点（Node） | 蓝图中的创作单元，具有标题、类型、标签、提示词信息等属性；类型分「蓝图」与「纯文本」两种 |
| 纯文本 | AI 编辑模式下的正文文件，进入后使用 AI 辅助创作 |
| 标签（Tag） | 节点的语义标注，内置如：设定、伏笔、大纲、世界观等；支持自定义 |
| 资源库 | 节点与标签的常用资源集合，可复用 |
| 链接（Link） | 节点/蓝图之间的连线，具备多种语义类型：直线、箭头、虚线等 |

## 3. 数据组织与创作链路

### 3.1 小说目录下的两类文件

1. **蓝图文件**（思维蓝图 / 节点工作流模式）
   - 黑色网格背景画布
   - 可创建节点，节点需编辑标题
   - 节点类型：思维蓝图本身（子蓝图）、纯文本
2. **纯文本文件**（AI 编辑模式）
   - 根据节点附带的提示词信息、前后节点的链接关系等进行 AI 辅助创作

### 3.2 典型创作链路（以一本新建小说为例）

```
空工作台
  └─ 创建小说（生成目录）
      └─ 创建「内容蓝图」
          ├─ 创建「世界观蓝图」──使用 AI 辅助创建多个纯文本节点并相互链接
          ├─ 创建「大纲蓝图」  ──使用 AI 辅助创建多个纯文本节点并相互链接
          │      └─ 在大纲蓝图中创建对应「章节蓝图」
          │             └─ 章节蓝图内基于大纲创建纯文本节点
          │                    └─ 点击进入纯文本节点 → AI 辅助正文创作
          └─ 世界观蓝图节点 ←链接→ 大纲蓝图节点
```

### 3.3 AI 上下文组装规则

创作正文时，提示词（上下文）由以下信息自动组装：

- **前后链接的节点**的内容与提示词信息
- **上级链接的蓝图、节点**（所在链路的上游信息）

> 具体组装策略（全量注入 / 按标签筛选 / token 预算控制）待技术方案阶段确定，见第 7 节待讨论问题。

## 4. 功能需求

| 编号 | 需求 | 说明 | 优先级建议 |
|---|---|---|---|
| FR-01 | 小说（项目）管理 | 创建/打开小说目录，目录内浏览全部文件 | P0 |
| FR-02 | 蓝图编辑器 | 黑色网格背景画布；创建节点；编辑节点标题；节点类型分蓝图/纯文本；点击蓝图节点可进入（子图嵌套） | P0 |
| FR-03 | 节点拖拽与画布缩放 | 蓝图节点和链接线条可自由拖动；整个蓝图可自由放大缩小 | P0 |
| FR-04 | 语义连线 | 类思维导图方式链接节点；支持直线、箭头、虚线等多类不同含义的线段 | P0 |
| FR-05 | 纯文本 AI 编辑器 | 进入纯文本节点后 AI 辅助创作；上下文按 3.3 规则自动组装 | P0 |
| FR-06 | 多 AI API 支持 | 支持多类 AI API（具体厂商范围待定） | P0 |
| FR-07 | 标签系统 | 为节点贴标签；内置标签：设定、伏笔、大纲、世界观等；支持自定义标签 | P1 |
| FR-08 | 资源库 | 节点与标签的常用资源库，跨小说/跨蓝图复用 | P1 |
| FR-09 | 全局蓝图总览 | 类 Obsidian 的整体蓝图节点图谱展示（右侧工具条按钮进入） | P1 |

## 5. 界面需求

### 5.1 整体布局（参考 PyCharm）

```
┌──┬─────────────┬──────────────────────────────┐
│图│  左侧创建栏   │  文件切换 Tab 栏（打开的文件）    │
│标│  （项目树等）  ├──────────────────────────────┤
│条│              │                              │
│  │              │     右侧内容展示框              │
│  │              │  （蓝图画布 / 纯文本编辑器）      │
│  │              │                              │
└──┴──────┬──────┴──────────────────────────────┘
          └─ 分界线可自由拖动调整
```

- 左侧：创建栏（项目树 + 竖排图标工具条）
- 右侧：内容展示区，顶部为打开文件的切换 Tab 栏
- 左右中间的分界线可自由拖动调整

## 6. 非功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-01 | 本地优先 | 创作数据存储于本地，不依赖云端服务 |
| NFR-02 | 画布性能 | 大量节点/连线场景下拖拽与缩放保持流畅 |
| NFR-03 | 可扩展 | AI API 以适配器方式接入，便于新增厂商 |
| NFR-04 | 数据安全 | API Key 等敏感信息本地隔离存储，不入库 |

## 7. 待讨论问题（Open Questions）

| # | 问题 | 备注 |
|---|---|---|
| 1 | 应用形态：桌面应用（Electron/Tauri）还是 Web 应用？ | 调研报告见 [02-技术调研报告.md](02-技术调研报告.md) |
